# Relayon

**Your webhooks, relayed right.**

Serverless-native webhook relay platform — receive events, enrich with AI, and route to any destination reliably.

## Status

🚧 **Phase 1 complete** — Dashboard foundation with auth.

## Stack

Angular 19 · NestJS 11 · Express 5 · PostgreSQL · MongoDB · Redis · Groq · Vercel

## Development

```bash
npm install --workspaces
npm run dev:dashboard
```
See apps/dashboard for the frontend.
